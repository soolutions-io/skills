# Sicurezza

Hai trovato una vulnerabilità nelle skill, nella CLI `portal` o nel portale
customers.soolutions.io? Non aprire una issue pubblica: usa
**[Report a vulnerability](https://github.com/soolutions-io/skills/security/advisories/new)**
(scheda *Security* di questo repository). La segnalazione resta privata tra te e noi.

Questo repository non contiene credenziali. Se ne vedi una (token, chiave, password),
segnalala allo stesso modo: verrà revocata, non solo rimossa.
